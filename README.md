### What I'm building

**[Magenta](https://magentactl.com)** is a self-hosted platform for operating and securing Windows fleets, including machines on unreliable connections. **Cadence** is its Rust agent: outbound-only, store-and-forward, and it runs only approved actions.

- Security posture checks mapped to CIS Controls v8 and PCI DSS v4.0
- Actions that need a second person's approval before they run
- A tamper-evident audit log and restore-tested, encrypted backups
- First complete Windows version running in pilot. [Early access is open.](https://magentactl.com/early-access)

Read how it's built: [magentactl.com/publications](https://magentactl.com/publications)
